# System Audit Snapshots

The files in this directory are dated audit snapshots and remediation inputs.
They preserve what was observed at their stated evidence cutoff; they are not
the current runtime or release authority.

Start with [`../CURRENT_STATE.md`](../CURRENT_STATE.md) for current state and
[`../DOCUMENT_AUTHORITY.md`](../DOCUMENT_AUTHORITY.md) for precedence. When a
snapshot conflicts with a later deployed release record, the later immutable
release evidence controls.
